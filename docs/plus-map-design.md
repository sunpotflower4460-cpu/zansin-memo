## 1. この文書の役割

Plusの主役は、目で理解できる地図の品質と、見えていなかった関係に気づくAI提案である。地図はAIを使わなくても成立する。アトリエ・作品集は、地図で見つけたものを育てたい人が任意で開く。

本書は画面・表示・操作・受入条件を決める。価格・権利・販売開始条件は [総合設計](plus-experience-design.md) と [課金・検証](plus-commerce-validation.md)、永続化・参照・AI候補の厳密な契約は [AI・データ契約](plus-ai-data-contracts.md)、実装順は [実装計画](plus-implementation-plan.md) を正本とする。

## 2. 無料とPlusの境界

無料の約束は [中核体験](core-growth-loop.md) と [中核UX](core-growth-ux.md) を維持する。文字の重なり、見えないボタン、全文に到達できない問題、読み上げ不能は無料・有料共通の不具合であり、課金差に使わない。

| 体験 | 無料で守るもの | Plusで増える価値 |
|---|---|---|
| 関係を理解する | 選んだ種の局所図と等価リスト、手動接続・解除 | 庭全体と複数のまとまりを同時に見渡せる |
| 多くの種を探す | 全件の検索・一覧、全接続への到達 | 密集した地図の整理、範囲・表示の切替、保存した視点 |
| 読みやすくする | 基本文字サイズ・コントラスト・操作領域・長文への到達 | 範囲に合わせた情報量の切替と、広い図の配置調整 |
| 場所を覚える | 通常の戻り位置と選択の保持 | 地図ごとの位置固定・名前付きの見方・配置の明示更新 |
| 関係を見つける | 共通語等のローカル候補、本人の自由な探索 | 許可した材料から意味・補完・対比等を読むAI候補 |
| 成果にする | 自分の芽、原文、基本の書き出し | 選択をアトリエへ渡し、地図と文章を作品に整える |

無料の図を読みにくくしてPlusへ誘導しない。Plusの価値は広い範囲を扱うときの理解・配置・移動・制作の質に置く。

## 3. 入口と基本画面

### 3.1 入口

- 庭に「地図で見る」を置く。既存の一覧・状態別の見方は維持する。
- 種の詳細から「広い地図で見る」を開くと、その種を焦点にする。地図の最初から探し直させない。
- 初回起動・保存直後には購入画面を出さない。有料機能を本人が開いたときの試用・購入は [課金・検証](plus-commerce-validation.md) に従う。
- データが少ない人向けの操作例は、実データと分離した例の庭を使う。例の接続・まとまり・作品を本人の記録へ混ぜない。

### 3.2 画面の構成

1. 上部: 戻る、地図名、範囲の説明。「全体」「周辺」を切り替える。
2. 中央: 地図。通常は本人の確定した関係と表示上のまとまりだけを示す。
3. 地図に重ねない補助操作: 「探す」「全体へ」「リスト」「見方を保存」。狭い幅では操作を折り返すか「表示」に収める。
4. 種を選んだとき: 内容の短いプレビュー。「全文」「つながり」「参考にする」を開ける。
5. 「候補を見る」を押したときだけAI候補を表示する。

アトリエ、作品集、AIチャットを常時並べない。スマホは地図・原文・候補の説明を一面ずつ開ける。原文を閉じたら、選んだ種と地図の位置に戻る。

### 3.3 地図の範囲と保存した見方

| 操作 | 表示する範囲 | 保持するもの |
|---|---|---|
| 全体 | 対象の庭のまとまり・独立した種・必要な確定接続 | 地図の位置、展開中のまとまり、選択、表示条件 |
| 周辺 | 焦点の種と直接接続。本人が「もう一段見る」を押した範囲のみ追加 | 焦点、戻る履歴、表示中／省略中の件数 |
| 保存した見方を開く | 本人が名前を付けた範囲・配置・表示条件 | `MapView` の設定。元メモの複製は作らない |

「保存した見方」は第三の関係種別ではなく、全体／周辺の設定を呼び戻す入口である。例:「曲の材料」「散歩の記録」。分類や保存名の入力を通常のメモ作成条件にしない。

保存する範囲は、次の2種類を画面で区別する。

- **選んだ種を保存:** 選択したIDの集合を保持。新しい種は自動追加しない。
- **この条件で見る:** カテゴリ等の条件を保持。新しく一致した種が入ることを保存時に説明する。

どちらも原文は現在の内容を読む。時点を固定した地図を残す場合は、[作品集](plus-atelier-collection-design.md) の明示的な保存を使う。

### 3.4 範囲と周辺展開の計算順

「全体」は現在の対象集合の全体を指し、常に保存済みの全メモを指すわけではない。次の順で表示を決める。

1. 固定集合なら選んだID、条件表示なら現在の条件一致から対象集合を決める。削除済み・参照不明の種を通常表示へ含めない。
2. 確定した `SeedConnection` のうち、**両端とも対象集合に含まれる接続**を表示計算の対象にする。
3. その集合と実接続の中で、全体／周辺の焦点・段数・接続のまとまりを計算する。
4. 最後に、まとまりの開閉、ズーム段階、画面内の描画量を決める。描画を省略しても集合の意味を変更しない。

「もう一段見る」は、この集合内の実接続を一段追加表示する操作である。集合外のメモを中継して別のメモへ到達したことにはしない。例えば対象がA・B、実接続がA–XとX–BだけでXが集合外なら、AとBを接続済み・同じ接続のまとまりとして描かない。

本人が選んだ種から集合外への確定接続がある場合は「この範囲の外につながる種」と別に示す。件数も、範囲内で描画を省いた「ほかN件」と混ぜない。「周辺を開く」で、その種を中心にした一時的な周辺表示へ進める。

一時表示は保存済み `MapView` と別の閲覧状態であり、元の固定集合・検索条件・配置を更新しない。上部に「保存した範囲の外を表示中」と戻る入口を示す。保存したい場合だけ、既存の「見方を保存」から新しい見方として残す。

一時表示へ進む前に `MapReturnContext` を保持する。戻るときは元の集合・焦点・段数・位置・展開・選択へ戻す。元の地図がその間に変更・削除された場合は、残る参照を使って変更を説明し、古い戻り文脈で現在の保存データを上書きしない。

## 4. 何がつながりなのかを誤認させない

| 表示対象 | 見た目・言葉 | 意味と禁止事項 |
|---|---|---|
| 本人が結んだ確定接続 | 実線。「つないだ関係」。旧移行分は「以前からのつながり」 | `SeedConnection` に存在する二者だけを示す。親子・原因・重要度を線の向きや長さで捏造しない |
| AI未採用候補 | 点線と「AIの候補」、候補の種類。選択中の候補を優先 | 候補一覧・原文・理由へ対応する。点線を見ただけで確定、材料採用、芽化しない |
| 表示上のまとまり | 面の囲み／見出しと「まとまり」 | 近くに置くための表示設定。中の種がすべて相互接続されている意味ではない |
| アトリエで参考にする種 | 選択マークと「参考にする」 | 材料選択。接続でも芽への採用でもない |
| 選択中・位置固定 | 枠と「選択中」、固定アイコン＋「位置を固定」 | 色だけに依存させず、読み上げにも同じ意味を渡す |

### 4.1 まとまりの作り方

初回Plusでは、確定接続からたどれるまとまりと、本人が選んだ表示上のグループを扱う。カテゴリでまとめる見方は本人が選ぶ。AIによるまとまり名・所属の変更は未採用案であり、表示設定へも無断適用しない。

確定接続から計算した集団には「接続のまとまり」等の構造を表す名前を使う。線でたどれるというだけで「同じテーマ」「同じ話」と断定しない。「カテゴリでまとめた表示」「本人が名前を付けたまとまり」とも区別して説明する。本人が付けた名前は、その本人の表示名として扱う。

接続のまとまりは§3.4の対象集合内の実接続から計算する。範囲内の接続が追加・解除されたら構造上のまとまりは変わり得るが、それを理由に本人の手動グループ名・所属・固定位置を変更しない。手動グループは表示時に現在の対象集合との共通部分を使い、絞り込みで見えなくなった種を所属から削除しない。カテゴリ表示も本人が保存したグループへの書込みにはしない。

まとまりと接続を別々に保持する。同じ種が複数のまとまりに属してよいが、種そのものは一件である。全体の種数はIDで重複除外し、まとまり内の件数と合算が一致しない場合は「複数のまとまりにある種を含む」と説明する。

最初の表示では一つの地図上の種の実体を一つにし、複数所属は「ほかのまとまりにも表示」で伝える。必要なまとまりへ切り替えて同じ種を見る。複製カードを追加する拡張を行う場合も、別の種や自己接続に見せない契約を先に定める。

まとまり同士の線を使う場合は「中の種どうしに確定接続がN件ある」という集約表示に限る。展開すると実際の両端を確認でき、まとまり名同士の意味的な関係と混同しない。AI候補を確定接続数へ加算しない。

### 4.2 候補を採用する操作

1. 「候補を見る」で、選択した範囲の候補を少数表示する。初期表示は最大3件を仮説とし、採用率のために枠を埋めない。
2. 候補を選ぶと、両方の原文・参照箇所・関係の種類・理由を読む。
3. 主操作は「つなぐ」「今回は見送る」。理由を自分の言葉にする操作は任意で開く。
4. 「つなぐ」の保存成功後にだけ実線へ変える。失敗中は点線を維持し、再試行で二重接続を作らない。
5. AI理由を本人の接続メモへ自動コピーしない。本人が明示して採用・編集した説明だけを本人の記述として扱う。

候補が古い、材料が編集・削除された、送信対象から外された場合の再照合は [AI・データ契約](plus-ai-data-contracts.md) に従う。古い理由でそのまま接続を確定しない。AIをオフにしても実線、配置、手動操作は利用できる。

## 5. 配置が変わりすぎない地図

### 5.1 通常の更新

- ノードは配列の順番ではなく `Seed.id` で識別し、同じ `MapView` の既存位置を優先する。
- 一つの追加・本文編集・タグ編集だけで地図全体を再配置しない。新しい種は、対象の近くの空いた位置へ追加する。
- 初回の自動配置は再現可能にする。再起動や表示順の変化だけで配置を乱数更新しない。
- 明示的な位置固定は、本文や関係の重要度を変えない。固定解除も接続解除ではない。
- 画面回転・文字拡大では読める大きさに再計測し、可能な範囲で相対位置と焦点を保つ。衝突を避けられない場合は、折り畳み／リストへの入口を提示する。

### 5.2 再配置のプレビュー

「地図を整える」は直接保存しない。

| 状態 | 表示・操作 | 永続データ |
|---|---|---|
| 通常 | 「地図を整える」 | 保存済み配置を表示 |
| 計算中 | 現在の図を保ち「配置を考えています」。キャンセル可 | 変更しない |
| プレビュー | 「この配置にする」「元に戻る」。固定した種を維持 | 仮の配置のみ |
| 保存中 | 二重適用を止める。図・メモは読める | 同じ操作IDで保存 |
| 保存成功 | 新配置を確定。操作単位の取り消しを提供 | 期待版に一致する更新だけを反映 |
| 保存失敗・競合 | 旧配置とプレビューを保ち再試行／キャンセル | 失敗を成功表示しない |

計算開始後に対象の種・グループ・ピンが変わったら、古い計算結果を黙って適用しない。「表示する内容が変わりました」と伝え、再計算する。別の編集を巻き戻す無条件Undoは行わない。

### 5.3 位置を動かす操作

ドラッグだけを操作手段にしない。種を選択し「配置を変える」から、隣に置く種／まとまりと上下左右を選べる。確定前に結果を確認できる。ジェスチャで動かす場合も、開始・終了がわかる編集モードを使い、通常のパンやタップで誤って配置を変えない。

## 6. 近づくほど詳しくなる表示

セマンティックズームは、地図全体をそのまま縮小して文字を極小にする処理ではない。表示範囲と文字サイズに応じて情報の種類を切り替える。

| 段階 | 主に見せるもの | 次の操作 |
|---|---|---|
| 広く見る | まとまり名、種の件数、独立した種、必要な集約関係 | まとまりを開く／選んだ範囲へ近づく |
| 周辺を見る | 種の題名または本文の冒頭、確定接続、焦点 | 種を選択／周辺を広げる／全文を読む |
| 内容を見る | 選んだ種の全文、確定理由または候補理由、参考にする操作 | 元の図へ戻る／アトリエへ進む |

- 題名がないメモには本文の冒頭を使う。表示用の短縮を原文の保存に反映しない。
- 長い日本語・英語の長語・URL・絵文字・改行を、固定の文字数だけで切り詰めない。視覚上は省略しても「全文」を開ける。
- ズームの境界付近で表示が頻繁に切り替わらないよう、切替に幅を設ける。
- 大きい文字ではカードを広げるか一段簡潔な表示へ切り替える。本人が選んだ文字サイズを縮小して収めない。
- 「広く／近く」ボタンと「このまとまりを開く」を用意し、ピンチ操作なしでも全段階に到達できる。

### 6.1 見た目の初期仕様

画面全体は生成り・和紙白・墨色を基準にする。全体図と周辺図は、土の中で菌糸が伸びる様子を手がかりに、濃い土色の上に丸い種と細い線を置く。以下の数値は実機で検証する際の目標とする。 [theme](../src/styles/theme.ts)

| 要素 | 初期仕様・確認すること |
|---|---|
| 図の土とカード | 畑の土のテクスチャを線の後ろに薄く置く。種とまとまりは丸い外周と明るい面で示し、文字を載せる面は均一にする |
| 文字の階層 | 周辺表示の種の主文は基準16、まとまり見出しは18、補足は12〜14の既存トークンを起点にする。文字倍率に追従し、広域では小さい主文へ縮めず件数・見出し表示に切り替える |
| ノード内の余白 | 基準12、本文と補足の間は8を起点にする。画像・件数・固定マークを本文に重ねず、それぞれの領域を確保する |
| ノード間の余白 | 基準16以上を初期目標とし、文字拡大後の実測サイズから衝突判定する。選択枠を含めて他の文字・操作領域に接触しない |
| 文字と線 | 線はカード外周で止め、本文・題名・件数の上を通さない。線の説明を出す場合は紙面の下地を設け、線との間隔を確保する |
| 線の強弱 | 確定したつながりは明るい実線で示す。菌糸のような細い枝の両端は、同じ確定接続の上に置く。選択中の接続は一段太く明るくし、候補は点線と凡例で区別する |
| 色の役割 | 通常文字は墨。選んだカードは琥珀色の二重枠で、採用前の候補は淡い朱の点線で示す。選択と候補は形でも区別する |
| 読みやすさ | 本文と背景はコントラスト比4.5:1以上、確定線と土の背景は3:1以上を目標に実色で測る。テクスチャと選択状態を含む組合せで確かめる |

現在のthemeは明色の定義であり、ダークテーマ実装済みとは扱わない。初回はアプリ全体の外観方針と揃え、OSが暗色でも背景・入力欄・文字の一部だけが反転して読めなくならないことを確認する。暗色テーマを追加する場合は背景・文字・線・紙面を一組のトークンとして設計し、明暗の両方で同じ意味と操作性を検証する。無料版の暗色・文字拡大に関する不具合も同時に直す。

## 7. 多量データと線の混雑

保存件数、接続件数、同時描画件数を分ける。読みやすさのために表示を絞っても、存在する記録や関係を消えたように扱わない。

- 全体ではまとまりへ集約し、画面外と折り畳み内は個別カードを描画しない。
- 選んだ種の周辺では、焦点に直接つながる線を先に示す。「もう一段見る」は明示操作にし、循環を無限展開しない。
- 比較版のマインドマップでは「地図にないメモ」から図に収まらないメモを探せる。現在の範囲すべてにも切り替えられ、選んだメモを元の中心のまま地図に表示する。
- 星座ではつながるまとまりを星と実線で描く。個々の星はメモを開く入口になり、図に収まらない星はその星座の「メモ一覧」から表示できる。
- 交差が多い場合は、選択中の関係を強調し、その他を弱める／畳む。すべてのグラフの交差ゼロを保証しない。
- 検索結果が現在の範囲外なら「この地図の外にあります。周辺を開く」と示し、戻ったときは元の表示条件へ戻す。保存した種集合へ無断追加しない。
- 独立した種は「未処理」や「育っていない」と表示しない。「つながりのない種」から同じ操作で開ける。
- レイアウト計算、検索、AI処理をメモ入力のたびに全件実行しない。計算結果には対象版を持たせ、古い非同期結果を破棄する。

### 測定計画

以下は**未計測の製品目標・検証条件**であり、対応済み件数や性能保証ではない。実機の端末・OS・ビルド・文字サイズ・データ条件を記録して判断する。

| 条件 | 記録するもの | 合格判断 |
|---|---|---|
| 50 / 500 / 2,000 / 5,000件 | 初回表示、検索、焦点移動、復帰、メモリ、保存量 | 全件へ到達でき、表示上限を欠落と誤認させず、落下・操作不能がない |
| 接続数6 / 50 / 200の焦点、循環、孤立 | 集約と展開、全件リスト、戻り先 | 線を捏造せず、処理が終わり、選択を失わない |
| 長い日本語・大きい文字・320/390/768 CSS pxのWeb | ラベル衝突、操作領域、全文、折り返し | 内容と操作が切れず、図／リストのどちらからも完了できる |
| 準備済み地図の焦点切替 | 入力から反映までのp95 | 暫定目標300ms以内。未達は条件と対策を記録し、販売可否を判定する |

同時描画上限は実測で決める。ノード数だけのfixture作成や、端末での保存件数だけを根拠に「5,000件でも快適」と表示しない。

### 7.1 Plusの品質差を確かめる比較

性能・到達性だけでなく、地図の品質向上が使う人に伝わることを販売前に確認する。**以下は未実施の評価計画であり、改善が確認済みという意味ではない。**

無料とPlusで同じ「知りたいこと・探したい材料・戻りたい場所」を課題にする。無料に存在しない全体図や保存ビューの操作を要求せず、無料では現在利用できる局所図・一覧・検索で達成してもらう。本文・接続・端末条件は揃え、無料の表示や検索を劣化させて差を作らない。

| 比較課題 | 達成してほしいこと | 主な観察 |
|---|---|---|
| 二つのまとまりの関係を知る | 用意した二つの手動グループに含まれる種と、グループをまたぐ実接続を理解する。無料では同じ種の一覧等から確認できる | 関係の読み違い、必要な操作、本人が何を理解したか |
| 接続の多い種から材料を探す | 指定の種から、探したい内容の材料へ到達し原文を読む | 操作数、探し直し、原文へ到達できない箇所 |
| 読んでから元の場所へ戻る | 原文や利用可能な別画面を見たあと、同じ対象・関係の確認を再開する | 戻り失敗、再検索、焦点を見失う箇所 |

Plus固有のアトリエ往復や保存した視点の再利用も確認するが、無料に同じ機能の利用を要求する比較にはしない。課題の達成に必要な操作と、その人が任意に内容を考えた時間を分けて記録する。

同じ端末で同じデータを使う比較を基本とする。順序による慣れを避け、無料→PlusとPlus→無料の順序を入れ替える。必要なら件数・接続密度・文字量・正解となる関係を揃えた同等fixtureを使い、使ったデータと順序を記録する。

判断は操作数・戻り失敗・関係の読み違いと、本人による「どこが便利になったか」の説明を合わせる。無料の基本課題は引き続き成功でき、Plusでは**少なくとも複数の課題で改善**を確認する。一つの速い操作、好みの配色、購入したいという回答だけで合格にしない。読み違い・操作不能が増えた場合は修正対象にする。

観察人数や操作数等の数値の合格線は、未検証の製品仮説として試用前・販売前に固定する。結果を見て都合よく基準を変えず、変える場合は理由と再確認を記録する。少人数の観察は問題と改善点を見つけるために使い、市場全体の優位性や購入率の統計的保証としない。

## 8. アクセシビリティとスマホ操作

- 地図と同じ範囲・焦点・選択を持つリストを常に提供する。課金状態にかかわらず全文、接続、候補の承認／見送りへ到達できる。
- VoiceOverでは、題名／冒頭、確定接続数、所属のまとまり、選択、位置固定、候補の有無を論理的な順序で読む。座標順だけを意味の順序にしない。
- 線・背景の囲み・装飾画像を個別に何百件も読み上げない。関係は「AとBをつないだ関係」の項目として操作できる。
- 候補採用後は「つながりを保存しました」を一回だけ伝える。全ノード更新のたびに読み上げない。
- パン／ピンチ／ドラッグ／長押しに、ボタンまたはメニューの代替を用意する。キーボードでも焦点移動・選択・戻るができる。
- 操作領域はiOSで44×44pt以上を製品目標とし、CSS pxを同じ単位とみなさない。密集するラベルのために操作領域を小さくしない。
- Reduce Motionでは位置の長い移動や拡大演出を抑え、変化した焦点を言葉と枠で示す。3D、常時揺れるノード、強い発光を導入しない。
- 原文や候補理由を開いたときはフォーカスを説明の先頭へ移し、閉じたら呼び出した種／候補へ戻す。

## 9. 空・エラー・権利状態

| 状態 | 表示と回復 | 禁止する挙動 |
|---|---|---|
| 種が0件 | 「ひとことから始められます」「メモを書く」「例を見る」 | 課金で中身が現れるような空地図 |
| 種が1件・接続なし | 一つの種を読める。手動接続・新規メモへ | 架空のつながりや、必要件数までのロック |
| 条件に一致しない | 条件と「絞り込みを解除」 | 全データが消えたような表示 |
| 保存した種が削除済み | その本文を図／プレビューに出さず、非表示件数と復元への入口 | 保存した見方のキャッシュから削除本文を復活 |
| 計算失敗 | 保存済み配置・リストを開ける。配置のみ再試行 | 無料の閲覧・入力まで停止 |
| AIなし・通信不可 | 手動地図と既存成果を利用。AIの状態は候補領域だけへ | 全画面のエラーや自動の通信再送 |
| 課金状態が不明 | 最後に保存した地図と無料コアを開く。権利確認を独立して再試行 | 支払い失敗と決めつけて成果を隠す |
| Plus満了 | 保存した配置・見方を読み、既存内容の基本修正・基本書出しができる | 地図や確定接続の削除、全面ロック |

満了後の新しい高度処理と既存成果の修正の境界は [課金・検証](plus-commerce-validation.md) に従う。読みやすくする通常のズーム・リスト・全文表示を新規生成扱いで禁止しない。

## 10. アトリエ・作品集との往復

- 地図上の「参考にする」は選択トレーへ種を入れる操作であり、確定接続を作らない。別のまとまりから追加してよい。
- 「アトリエで開く」で、選択した種と、見ていた部分（元のメモ／芽の文）を渡す。全周辺を無断で材料にしない。
- 戻り先として地図ID・焦点・範囲・位置・展開状態を保持する。制作中に元が変わったときは、存在する範囲で戻し、変更点を説明する。
- アトリエで芽を採用しても、地図の配置と接続を自動変更しない。芽の表示だけが既存の保存契約に従って更新される。
- 作品集の「地図と文章」では、本人が選んだ範囲の確定接続だけを初期出力する。AI未採用の点線は初回版の作品出力に含めない。
- 出力用に整えた配置を、元の `MapView` へ逆流させない。地図から作品へ、作品から現在の原文へたどれるが、それぞれの版は別に保持する。

詳細は [アトリエ・作品集設計](plus-atelier-collection-design.md) を参照。

## 11. 初回Plusと後続の範囲

**初回Plusの必須範囲:** 全体／周辺、保存した見方、まとまりと確定線の区別、安定配置・ピン・再配置プレビュー、段階的なズーム表示、全件へ到達するリスト、理由付きAI候補の個別採用、アトリエとの往復、地図と文章の1ページ出力。

**後続:** 自由な地図テンプレートの大量追加、複雑な期間比較、共同編集、公開ギャラリー、AIによる大規模な所属再編、3D表現。これらを初回販売条件に追加しない。共同編集・公開・3Dは別の設計承認なく実装しない。

実装時は、表示モデル／配置計算／描画／操作／保存を分ける。現在の局所図をいきなり置換せず、同じ `Seed`・`SeedConnection` を読むPlusの表示から段階的に加える。依存ライブラリの採用は、小画面・文字拡大・読み上げ・多量データの小さな検証で決める。

## 12. 受入例

| ID | 操作・条件 | 必須結果 |
|---|---|---|
| PM01 | A–B、B–Cだけが確定。全体／周辺／まとまりを切替 | A–Cを確定線として描かない。集約から実際の両端へ戻れる |
| PM02 | Aを「音楽」「散歩」の両方のまとまりへ | Seedは1件。所属だけで線や芽が増えず、総数を二重計上しない |
| PM03 | AI候補を表示・閉じる・見送る | 原文、確定接続、芽、保存済み配置が変わらない |
| PM04 | 候補採用の保存失敗と再試行・連打 | 成功前は実線にせず、成功後も一つの無向接続だけ |
| PM05 | 位置を固定した種を含む地図へ一件追加し再起動 | 固定位置と既存の見方を維持。追加で全体を無断再配置しない |
| PM06 | 再配置プレビュー中に元の種・ピンを変更 | 古い配置をそのまま確定せず、旧配置と作業を失わない |
| PM07 | 長文・大きい文字・狭い幅で全体から全文へ | 字を極小にせず、全文・関係・操作に到達できる |
| PM08 | 5,000件・高次数・循環の測定用データ | 省略数を説明し全件到達。操作不能・無限展開・捏造線なし。実測条件を記録 |
| PM09 | VoiceOver／キーボード／ドラッグなし | 範囲変更、選択、配置、AI判断、アトリエ往復ができる |
| PM10 | 地図外の検索結果を開いて戻る | 元の範囲・焦点・位置を復元。固定集合へ無断追加しない |
| PM11 | 参考にする種を選びアトリエで比較して戻る | 接続・芽は明示採用分以外変わらず、戻り場所を保持 |
| PM12 | Plus満了／権利確認失敗／オフライン | 無料コアと保存済み成果を読め、基本修正・基本書出しを続けられる |
| PM13 | 保存した見方の参照メモを削除・復元 | 削除本文を表示せず、復元後は同じ参照へ。地図からメモを再生成しない |
| PM14 | 全データ削除中に配置計算／AI処理が完了 | 古い結果を保存せず、配置・候補・キャッシュから削除内容が復活しない |
| PM15 | 固定集合A・B、実接続A–X–B、Xは集合外 | A–Bを確定線や同じ接続のまとまりとして描かない。「もう一段見る」でも集合を拡張しない |
| PM16 | 範囲外のXを一時表示して戻る。途中で元の地図が更新される場合も確認 | 元scopeを変更せず、戻り文脈を復元。更新があれば説明し、古い配置で保存データを上書きしない |
| PM17 | 条件に合う種を追加・条件を変更・確定接続を解除 | 条件表示と接続のまとまりだけが規則どおり変わり、固定集合・手動グループ所属・固定位置を無断変更しない |
| PM18 | §7.1の3課題を、無料／Plusで同条件・順序を入れ替えて確認 | 無料コアを維持し、Plusは複数課題の改善と本人の説明を記録。未検証の見た目だけで品質差を宣言しない |

実装済み・自動検証済み・Webで確認済み・iOS実機で確認済み・初見確認済みを分けて [実装計画](plus-implementation-plan.md) に記録する。図が表示できただけで、Plusの品質差が完成したと判定しない。
