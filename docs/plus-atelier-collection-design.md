# Plusのアトリエ・作品集設計 — 自分の言葉を育てて、残す

更新日: 2026-11-27（日本時間）

## 1. 役割と範囲

地図とAI提案を主役にし、そこで気になった種を育てたいときにアトリエを開く。作品として残したいものができたときに作品集を使う。地図を見るだけ、種のまま置くだけ、下書きで閉じるだけでも一回の利用は完了する。

アトリエは、選んだ原文を読み、複数の案を比べ、好きな部分を残し、自分の言葉へ編集する場所である。作品集は、本人が選んだ版を私的に残す場所である。常設の汎用AIチャット、作品の自動量産、提出期限、公開ランキングを追加しない。

共通の方針は [総合設計](plus-experience-design.md)、地図との境界は [地図設計](plus-map-design.md)、データとAIの正本は [AI・データ契約](plus-ai-data-contracts.md)、課金・失効は [課金・検証](plus-commerce-validation.md)、工程は [実装計画](plus-implementation-plan.md) に従う。

### 現在ある機能と追加設計

| 根拠 | 既存の実装 | 追加するもの |
|---|---|---|
| [SynthesisScreen](../src/screens/SynthesisScreen.tsx) | 中心の種と本人が選んだ材料を読み、芽の一文を書く。下書き・全文・保存失敗時の保持がある | `AtelierProject` と `AtelierRevision` による独立した下書き・比較・一節固定 |

現在の芽を書く機能をアトリエへ移して有料化しない。過去文書の `SeedLink` という呼び方を実装名にせず、確定接続は既存の `SeedConnection` を使う。

## 2. 初回Plusの必須範囲と後続

| 初回Plusに含める | 後続として設計を残す |
|---|---|
| 参考にする原文の選択・全文・由来へ戻る | 音声・画像・Web取り込みの新設 |
| 独立した作業中の文と、節目の版を保存 | 大規模な共同編集・コメント・公開配信 |
| 案の比較、好きな一節の固定、元に戻る | 多数の分岐を一度に扱う複雑な編集環境 |
| 本人が押したときの短い見方・題名・構成のAI候補 | 自由な長文チャット、無制限の作品生成 |
| 案を自分で直す、芽にする内容の明示採用 | AIによる原文・芽・作品の自動更新 |
| 私的な作品集、ことばカード、地図＋文章1ページ | 複数ページの小冊子、凝った印刷用入稿、テーマの大量追加 |
| 元メモと成果の相互参照、失効後の閲覧・基本編集・基本書き出し | SNSや外部サービスへの自動投稿 |

アトリエと作品集は任意の入口だが、上表の初回範囲は初回Plusの製品に含める。未完成の機能を「今後使える特典」として販売しない。小冊子を初回販売の工程へ混ぜない。

## 3. 画面の置き方

### 3.1 入口

- 地図で種を選び「参考にする」→「アトリエで開く」。地図の周辺全件を自動で取り込まない。
- 種／芽の詳細から「アトリエで考える」。見ていたのが元のメモか芽の文かを引き継ぐ。
- 庭の「つくったもの」から作業中の案と作品集を開く。Homeに新しい大きな機能カードを並べない。
- 新しくメモする操作、無料の「芽を書く」、既存のテンプレ変換は従来の場所にも残す。

### 3.2 スマホの一面ずつの構成

| 画面 | 主にすること | 常にわかるもの |
|---|---|---|
| 参考のメモ | 読む、追加・除外、使う部分を確認 | 原文／芽の文の区別、選択した件数、地図へ戻る |
| 考える | 自分で書く、任意の短いAI候補を読む | 今の作業中の案、参考にした原文への入口 |
| 案を比べる | A/B等の案を一つずつ開き、選ぶ・一部を残す | 案の名前、節目の版、由来、元の案へ戻る |
| 残し方を選ぶ | 作業中のまま閉じる／芽にする／作品集へ | どの文・どの版を、どこへ残すか |
| 作品を見る | 読む、編集版を作る、材料を見る、書き出す | 作品名、保存した版、非公開、出典の状態 |

狭い画面で原文・チャット・案の比較・地図を四分割しない。「参考のメモを見る」を開いても入力は保持し、戻ると同じカーソル位置に戻す。案の切替はスワイプのほか、名前付きボタンでも行える。

## 4. アトリエの一周

### 4.1 原文を選ぶ

参考にするものは、本人が選んだ `Seed` の `body` または `synthesis.statement` に限る。本文全体を使う場合も、どのメモのどの部分か確認できる。同じ種の原文と芽を両方使う場合は別の参照として表示する。

- 読み取り用の引用と、作業中の文を別欄にする。引用欄の編集で原文が変わるように見せない。
- 引用の内部材料を再帰的に複製しない。本人が今見た文章の範囲を扱う。
- 一件だけでも始められる。アトリエで考えるために、接続・タグ・成長状態の変更を要求しない。
- AIを使う場合だけ送信範囲を確認する。アトリエを開いたことや材料を選んだことを、外部送信への同意にしない。
- 参考にするメモから外しても、元のメモ・確定接続・既存の芽は消さない。

### 4.2 自分で書く入口を先に用意する

初期の問いは「ここから、どんなことが浮かびますか」。必ず作品にする、企画にする、解決することを求めない。本文は空の下書きから書ける。題名は任意で、案を区別するための「案A」等は表示名として使える。

AI補助は「別の見方」「題名の案」「構成の案」の小さな操作から呼ぶ。初回はこの3種類に絞る。各種類の出力上限・送信上限・費用の管理は [AI・データ契約](plus-ai-data-contracts.md) に従い、UIから無制限の生成を呼び出せる入口にしない。

### 4.3 AIの提案は、作業中の文と分ける

関連の候補 `ConnectionProposal` と、制作補助 `AtelierSuggestion` を混ぜない。短い提案には、材料に基づく部分とAIが新しく提案した解釈を示す。元メモに書かれていないことを引用として表示しない。

「この案を使う」は、選んだ候補を下書きへ挿入する操作である。接続の確定・芽化・作品集への保存・公開は起こさない。挿入位置を示し、既存文の置換をする場合は対象を見せる。編集後もAIを材料にした由来を記録し、本人の原文と取り違えない。

AIが失敗しても、書いた文と参考のメモはそのまま使える。「別の見方」を何度押しても、既存の案を自動で差し替えない。

### 4.4 案と版を分ける

- **作業中の文:** 自動下書き保存する現在の入力。キー入力のたびに全材料や全履歴を複製しない。
- **案:** 同じ材料から考えた別の方向。初期表示では2案程度を比較し、必要なものだけ開く。
- **版:** 本人が「この状態を残す」等で確定した節目。`AtelierRevision` として後の編集で上書きしない。

案を切り替えても他の案の入力を失わない。過去の版を開く操作は閲覧であり、現在の作業中の文を巻き戻さない。「この版から考え直す」で新しい作業枝を作る。過去版から分岐しても、既存の芽と作品は変更しない。

スマホでは原則一案ずつ表示し、比較対象へ名前付きボタンで移動する。「違いを見る」は変更箇所と共通箇所を文章でも読めるようにし、赤／緑の色だけで区別しない。

### 4.5 好きな一節を固定する

本人が選んだ一節へ「この言葉を残す」を付ける。その案でAIを再度使うときは、固定した文字列を変更せず、それ以外の短い候補を返す。

- 固定は案・版ごとに扱う。別の案まで一括で固定・解除しない。
- 文字位置の数値だけで固定範囲を管理しない。編集で位置がずれても対象の一節を追える識別子と内容照合を使う。
- AIが固定一節を変えた場合は、適用可能な結果として扱わない。元の案を保持し、失敗・再試行の利用枠は共通契約に従う。
- 本人が固定部分を直接編集する場合は「固定を外して編集」を選べる。編集不能な文章を作らない。
- 参考にした原文自体を編集不可にする意味ではない。原文の変更と下書きの一節固定を別の操作にする。

## 5. 何を採用したのかを分ける

| 本人の操作 | 変更するもの | 変更しないもの |
|---|---|---|
| AIのつながりを「つなぐ」 | 確定接続 `SeedConnection` | アトリエ案・芽・作品 |
| 参考にするメモへ追加 | アトリエの材料選択 | 確定接続・原文・芽 |
| AIの短い案を「この案を使う」 | 作業中の下書き。由来を保持 | 原文・確定接続・現在の芽・作品 |
| この状態を残す | 比較できる節目の `AtelierRevision` | 原文・現在の芽・既存作品 |
| 芽にする | 本人が確認した中心の `Seed.synthesis`。既存契約に従う | 他の材料の本文・状態・接続 |
| 作品集に残す | 選んだ版を基にした私的な `CollectionItem` | 現在の芽・成長状態・公開状態 |
| 咲いたと感じた状態へ変更 | 既存の本人による成長操作 | 作品集保存だけで自動実行しない |

作品を残したことを「創作の成功」と判定せず、芽や花の状態を自動で進めない。

### 5.1 芽へ渡すとき

1. 採用する案・版・一文を本人が選ぶ。
2. 「このメモに芽を残します」で中心を確認する。中心の原文は必ず材料に含める。
3. 既存の `SynthesisScreen` と同じ原文・材料確認へ渡す。アトリエから `Seed.synthesis` を直接上書きしない。
4. 既存の芽がある場合は「今の芽を見直す」を明示する。新規芽として黙って置き換えない。
5. 元の文章が変わっていたら、アトリエの案を保持して現在の文章と比較する。本人が確認し直した `expectedText` でだけ保存する。
6. 保存成功後、採用したアトリエ版と芽の参照を残す。失敗・連打・再試行で二重採用しない。

既存の芽の下書きがある場合も、それを無断置換しない。どちらを開くか選べるようにし、アトリエの作業は独立した下書きとして残す。

過去の材料のまま作品として残したい場合は作品集へ進める。古い材料スナップショットを現在の原文と一致したように見せて `promoteToSprout` の照合を通さない。

## 6. アトリエの状態表

| 状態 | 画面・許可する操作 | 保持・回復 |
|---|---|---|
| 作業前 | 原文を読み、書く／閉じる | 開いただけで空の作品を増やさない |
| 下書き編集中 | 本人の入力、材料確認、案の切替 | アプリ終了・戻る・タブ移動から再開 |
| AI送信確認 | 対象範囲、利用する機能、同意 | キャンセルしても選択・文を維持 |
| AI処理中 | 文と原文を読む。キャンセル可能 | 送信時の案／材料版を固定して結果と照合 |
| AI処理中に本人が編集 | 入力を優先 | 変更前の後着結果は受領・適用せず、予約枠を返す。現在の版での依頼は本人が再操作する |
| 候補あり | 原文・理由を読む、使う／見送る | 未採用のまま芽・作品にしない |
| 材料に変更あり | 当時／現在を比べる | 採用済みの版を黙って改稿しない。新採用時は再確認 |
| 材料が削除・参照不明 | 引用を隠し状態を伝える | 新AI送信・新たな原文としての採用は止め、復元／材料の見直しへ。本人の文と固定した一節は保持 |
| 自動発見の対象から除外 | 自動候補に使わない。本人の原文閲覧は維持 | 手動検索・明示的な材料選択・本人の芽への採用を妨げない |
| AIへ送らない材料を含む | 外部AI処理だけを止め、対象を説明する | ローカルの閲覧・比較・編集・本人の芽への採用は可能。文と固定した一節を保持 |
| 保存中 | 同じ操作の二重実行を止める | 入力を先に消さない |
| 保存失敗・競合 | 入力と対象を残し再試行／別案として保持 | 成功通知を先行しない。競合を自動上書きしない |
| AI利用枠の終了・オフライン | 手動編集、既存案・原文の閲覧 | 作業中に購入画面へ強制移動しない |
| Plus満了 | 既存の下書き・版の閲覧、本文等の基本編集、基本書き出し | 新AI・新たな高度作成の制御は課金契約に限定 |

AIのキャンセル後・同意撤回後・全データ削除後に返った結果を保存しない。詳しい要求世代・対象版・権限照合は [AI・データ契約](plus-ai-data-contracts.md) に従う。

## 7. 作品集 — 私的な成果を、選んだ形で残す

### 7.1 共通動作

- 初期状態は常に非公開。作品集へ保存しても外部へ送信しない。
- 作品名は任意。本文、選んだ版、参考のメモ、作成時の地図へ戻れる。
- 保存前に「この版を残す」を確認する。最新の作業中の文を勝手に作品へ反映しない。
- 一つの芽・アトリエから複数の作品を作ってよいが、自動複製しない。
- 作品の本文を編集すると編集用下書きを作り、本人の「変更を保存」で節目の `CollectionRevision` を確定し、`CollectionItem` の現在版参照を更新する。参照したアトリエの固定版と材料のスナップショットは保持する。キー入力ごとの全履歴は作らず、本文更新の期待版照合・保存失敗時の保持を実装する。
- 原文が変わった場合は「参考のメモに更新があります」と示す。現在の原文を読む／更新を反映した別版を作る操作を分ける。
- 接続を外しても保存時の地図を現在の地図に描き直さない。「この作品を作ったときの地図」と「現在の地図」を区別する。

### 7.2 初回に作れる形式

| 形式 | 何を残すか | 初回の編集範囲 | 初回の出力 |
|---|---|---|---|
| ことばカード | 本人が選んだ一文・短い文章、任意の題名 | 文章、少数の紙面スタイル、文字の配置、必要な出典表示 | PNG。読みやすいプレビューと同じ内容 |
| 地図と文章の1ページ | 本人が選んだ範囲の確定した関係と、その気づき・芽・作品文 | 図の範囲、焦点、文章、上下の配置、出典の表示範囲 | 1ページPDF。確認用の画面プレビューを備える |

初回の紙面スタイルは少数に限定する。和紙・文字・余白を調整し、買い切り装飾素材やテーマの大量制作を先に行わない。テクスチャは文字と線の視認性を妨げない。

ことばカードは4:5の縦比率、1ページPDFはA4縦を初期仕様とする。出力解像度と最終フォントは実装時に実ファイルで確認して決め、未検証の高解像度・印刷品質を宣伝しない。両方とも基本テキスト書き出しへ戻れる。

### 7.3 長文・大きい地図の扱い

- 一枚へ収まらない原文を勝手に要約しない。文字を極端に縮めたり末尾を切ったりしない。
- 「この文章は一枚に収まりません」と示し、本人が抜粋する／範囲を絞る／通常のテキストで書き出すを選べる。
- 抜粋は選んだ範囲を保存し、元の全文へ戻れる。抜粋したことがプレビューでわかる。
- 地図は本人が選んだ範囲だけを作品化する。すべての種を小さく詰め込まない。
- 初回版の作品地図にはAI未採用候補を含めない。本人の確定接続と表示上のまとまりを区別した凡例を付けられる。
- 作品用のレイアウト調整を通常の地図配置や原文へ反映しない。

### 7.4 小冊子は後続

後続では、本人が選んだ `CollectionItem` の版を順番に並べ、表紙・目次・本文ページを作る。勝手な作品選択・並べ替え・AIによる追記はしない。

小冊子の実装前に別途確定するものは、用紙サイズ、ページ数の運用上限、長文の改ページ、画像・地図のキャプション、余白・禁則、フォント埋め込み、メモリ制約、ページ単位の確認である。少なくとも長い日本語、文字拡大、複雑な地図を含む実PDFを全ページ確認する。初回Plusのカード／1ページ出力から、未検証の冊子生成へ自動拡張しない。

## 8. 引用・変更・削除・書き出し

### 8.1 固定した成果と現在の原文

`MapView` は現在の種を参照する表示設定。作品の地図・文章は、本人が選んだ時点の版として残す。アトリエの節目版も、後の原文変更で自動更新しない。データの細部は [AI・データ契約](plus-ai-data-contracts.md) に従う。

| 起きたこと | アトリエ／作品側の扱い |
|---|---|
| 元メモの本文を編集 | 当時の引用を保持し更新の存在を表示。AIの新要求や新しい芽への採用は現在の材料を再確認 |
| タグや題名だけを変更 | 本文変更と区別する。更新時刻だけを理由に文章が変わったと表示しない |
| 確定接続を解除 | 現在の図から線を外す。作品に残した当時の図・材料の採用履歴は別に扱う |
| 元メモを最近削除へ | 原文引用・原文カード・AI送信・通常出力ではその内容を隠す。本人が採用・編集した独立作品文は勝手に消さず、参照状態を表示 |
| 元メモを復元 | 参照を同じIDへ戻す。本人の案や作品を再生成しない |
| 個別の作品を削除 | 元メモ・芽・他の作品を連鎖削除しない |
| 全データを削除 | 作品、版、引用、地図スナップショット、下書き、出力キャッシュも対象。古いAI結果や再開処理から復活させない |

引用の非表示は、固定した版の内容を裏で新しい文章へ書き換える操作ではない。削除された原文をキャッシュから再表示しないための表示・出力規則である。削除済みの引用を含む古いサムネイルやレンダリングキャッシュも無効化し、通常の再出力ではマスクを反映する。

本人がすでに外部へ書き出したファイルを、アプリ内の削除で回収できるとは説明しない。通常の作品書き出しと、削除済み・下書き等も含む全データJSONは範囲を明示して分ける。既存の復元インポート未実装という制約を隠さない。

### 8.2 出力確認

1. 書き出す作品版と、参考情報の収録範囲を選ぶ。
2. 実際の出力と同じレイアウトでプレビューする。
3. 内容、本文の省略、地図の範囲、出典、見える文字を確認する。
4. 「書き出す」で端末の保存／共有シートへ進む。作品集保存から外部投稿を自動で行わない。

通常出力へ内部ID、端末上のパス、本文を含むデバッグ情報、非選択のメモを混ぜない。元のメモの題名や日付も、収録対象として確認できるようにする。

PDFは実ファイルのページ数・文字切れ・日本語・図の線・フォントを確認する。PNGも実解像度で文字と線が読めるかを確認する。画面のプレビューだけを出力品質の証拠にしない。

## 9. 失効後も自分の成果を使える

| 操作 | 初回Plusの権利中 | 満了・無料へ戻った後 |
|---|---|---|
| 原文・芽・確定接続 | 使える | 同じ無料の権利を維持 |
| 既存のアトリエ下書き・比較版を読む | 使える | 維持 |
| 既存の作業中の文、題名、参考のメモの基本編集 | 使える | 維持。既存入力を人質にしない |
| 新しいAI補助・新規の高度な比較作業 | 利用枠等の範囲で使える | 制限対象。保存済みの案は消さない |
| 既存作品の閲覧・本文等の基本編集 | 使える | 維持 |
| 作成済みの出力ファイルを開く・取り出す | 使える | 維持。後付けの透かしや画質劣化を加えない |
| 基本編集した文章の標準テキスト／JSON書き出し | 使える | 維持。新しい編集内容を持ち出せる |
| 保存済みの形式・テンプレート・配置設定で既存作品を再出力 | 使える | 手動編集した本文もPNG／PDFへ再出力できる |
| 新しい高度な作品構成・将来の追加形式 | 提供済みの権利に従う | 制限対象。基本テキスト／全データ書き出しは維持 |
| 削除・原文へのアクセス・全データ書き出し | 使える | 同じ権利を維持 |

既存成果の基本編集に新しい節目版の記録が必要な場合、その保存を「新規の有料版作成」と扱って止めない。新規機能の利用と、本人の成果を安全に編集・保存することを分ける。詳細の権利名・状態は [課金・検証](plus-commerce-validation.md) へ統一する。

既存作品の持ち出しに再課金を必要とさせない。保存済みの形式・テンプレート・配置設定を使い、本人が手動編集した本文もPNG／PDFへ再出力できるようにする。新しい高度な作品作成、別形式・別テンプレートの新規適用はPlus操作として分ける。再出力前の古いファイルは「最後に書き出した内容」と表示し、現在編集中の文と混同しない。長文が同じ紙面に収まらない場合は、無料で抜粋の見直しと標準テキスト書き出しを選べる。

## 10. データと実装の境界

以下は責務の説明であり、別の保存schemaの定義ではない。厳密な型・移行・削除・要求照合は [AI・データ契約](plus-ai-data-contracts.md) を正本とする。

| モデル | 責務 | 混ぜないもの |
|---|---|---|
| `AtelierProject` | 作業中の文、材料参照、案、戻り先、継続可能な下書き | `Seed.synthesis` の確定状態、課金権利そのもの |
| `AtelierRevision` | 本人が残した節目の文・由来・材料の採用時点・固定した一節 | 後から自動で書き換わるライブ本文 |
| `AtelierSuggestion` | 明示要求に対する未採用の短いAI案、根拠、対象版 | 確定接続、本人の確定文、作品の自動生成 |
| `CollectionItem` | 作品の一覧情報・順序・現在の確定版への参照 | 公開投稿や共有済みという扱い |
| `CollectionRevision` | 本人が確定した文面・構成・必要な地図の固定版、原文・アトリエへの由来 | 自動更新される原文、キー入力ごとの全履歴 |

既存の `GardenStoreV2` へ未知フィールドを無計画に足さない。移行後の保存形式・単一のwriter・全削除の世代管理へ統合する。旧正規化処理に新規データを渡して失わないよう、追加モデルと読書き契約を先に実装する。

画像・PDFのプレビューや出力は、原文の保存と別の再生成可能なキャッシュとして扱う。生成失敗で原文・案・作品版を失わない。長い版履歴・多材料・大きい出力の容量を実測し、単に「作品無制限だから容量も無限」とは扱わない。

## 11. 品質とアクセシビリティ

- キーボード表示中も入力欄・保存状態・戻るを操作できる。原文を見るためにキーボードを閉じても、IME変換中の文や選択を失わない。
- 文字拡大では画面を縦に流し、比較の左右二列を必須にしない。出力用の紙面とアプリ内の読みやすい閲覧を分ける。
- VoiceOverで、原文／芽の文／AI候補／本人の作業文／確定作品の区別を読める。
- 一節固定はテキスト選択メニュー以外に、段落を選んで固定する入口も用意する。小さい文字の精密ドラッグだけを要求しない。
- 差分は追加・削除・変更の言葉でも伝える。比較対象の切替後に読み上げの位置が毎回先頭へ飛ばない。
- 長文・Unicode・絵文字・改行・日本語の禁則を含む素材で、画面と実出力の両方を確認する。
- 保存・AI処理・出力を別の状態として表示し、画面に表示されたことを永続化成功とみなさない。
- 原文を読んだ時間や作品数を達成評価にしない。閉じることや採用しないことを失敗として通知しない。

応答時間・メモリ・出力解像度の数値は、実装後の端末測定で確定する。本設計の段階では未計測であり、性能保証はしない。

## 12. 受入例

### アトリエ

| ID | 操作・条件 | 必須結果 |
|---|---|---|
| PA01 | 地図で未接続の2種を選びアトリエへ | 選択部分が材料になり、確定接続・芽は増えない |
| PA02 | 一つの種だけで書く／何も書かず閉じる | 件数ロックなし。空作品を自動追加しない |
| PA03 | 原文と芽の文を別々に選ぶ | 見た部分と保存した引用が一致し、材料の材料を再帰コピーしない |
| PA04 | 案Aを書き、案Bを作り、途中終了・再起動 | 両案と現在の入力を再開でき、既存の芽は変わらない |
| PA05 | 一節を固定してAI候補を再要求 | 固定文を保つ。変更された結果を黙って適用しない |
| PA06 | AI処理中に入力・材料変更／同意撤回 | 入力を保持し、古い後着結果は受領・適用せず予約枠を返す。現在版での依頼は本人の再操作とし、撤回後は保存・再送しない |
| PA07 | AI候補を一部使い、自分で編集 | AI由来と原文を区別して保存。接続確定・芽化・作品化は別操作 |
| PA08 | 比較版を芽にする際に元メモが変更済み | 元の案を保持し、現在の材料を再確認。expectedText契約を迂回しない |
| PA09 | 中心に既存芽・芽の下書きがある | 無断上書きせず、見直しと下書きの扱いを本人が選べる |
| PA10 | 芽保存が失敗、連打、再試行 | 文章と選択を失わず、採用は一回。保存成功前に完了扱いしない |
| PA11 | VoiceOver・大きい文字・ドラッグなし | 原文、比較、一節固定、編集、芽への採用を完了できる |
| PA12 | Plus満了中に既存の下書きを編集・書き出し | 保存済み成果と基本編集・書き出しを維持 |
| PA13 | 自動発見から除外／AI非送信の材料を本人が手動選択 | ローカルの材料閲覧・比較・芽の採用は可能。除外は自動推薦、非送信は外部AIだけに適用 |

### 作品集と往復

| ID | 操作・条件 | 必須結果 |
|---|---|---|
| PC01 | 案Bの版2を作品集へ保存後、案Bを変更 | 作品は版2のまま。自動更新・公開・芽化しない |
| PC02 | 作品から元の地図・原文へ戻り、作品へ戻る | 選んだ作品版と地図の戻り場所を保持 |
| PC03 | ことばカードに長い日本語を指定 | 自動縮小・隠れた末尾切れをせず、抜粋等を本人が選べる |
| PC04 | 地図と文章1ページを出力 | 選んだ範囲・確定関係・文章が実PDFと一致。AI候補や非選択メモが混入しない |
| PC05 | 作成後に原文を変更・接続を解除 | 当時と現在を区別し、保存済み作品を黙って描き直さない |
| PC06 | 参照元を削除した作品を開く／再出力 | 引用・原文カードをマスクし、古い画像キャッシュから露出しない。独立した本人の文は保持 |
| PC07 | 個別作品を削除 | 元メモ・現在の芽・他作品を削除しない |
| PC08 | Plus満了後に既存作品を基本編集し、同じ保存済み形式で再出力 | 最新の文章をPNG／PDFへ反映でき、標準書き出しも可能。別形式の新規適用と区別できる |
| PC09 | PDF/PNG生成の途中失敗・アプリ中断 | 原文と確定作品版は残り、同じ版から再試行できる |
| PC10 | 全データ削除中に生成結果が返る | 下書き・版・引用・出力キャッシュから内容が復活しない |
| PC11 | 通常の作品出力と全データJSONを使う | 収録範囲の違いを説明し、削除本文・内部ID等が通常出力へ混入しない |
| PC12 | 初見利用者が何も公開せず作品を残す | 私的に保存されたことを理解し、共有は本人が選ぶ別操作とわかる |

初回Plusの販売判断は、手動でも地図→アトリエ→作品が一周すること、AIなしでも既存成果を使えること、実機と実出力で内容が保持されることを含めて行う。小冊子は未実装でも初回範囲の未完了と混同しない。
