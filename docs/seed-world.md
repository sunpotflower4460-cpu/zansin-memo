# Seed World

## どんな種か
Kizashi Notes の「種」は、完成文ではない小さな断片です。

- ふと思った一言
- まだ形になっていないアイデア
- 何度も気になるテーマ
- 会話で残った言葉
- 心が動いた瞬間や違和感
- 未来の自分への小さなサイン

曖昧さは欠陥ではなく、成長余地として扱います。

## どんな世界を表現しているか
このアプリは「内側の森」を表現します。

- 種: 小さなメモ
- つながり: 本人が一緒に考えたいと結んだメモ同士の関係
- 栄養: ある種を考える材料となる、つながった別のメモの役割
- 芽: 元の種や選んだ材料から、本人が言葉にした新しい可能性・問い・方向
- 木: 既存の育ち状態。既存記録を保持し、新しい昇格条件は公開前の中核設計に含めない
- 森: 大きなテーマ群
- 星 / 水脈: 繰り返し現れる言葉
- 浮上する光: 今の自分に必要なメモ

世界観は自然・成長・内省を中心にしつつ、実用メモとして成立させます。

初めて使う人には、まず「残す・つなげる・芽にする」を操作とともに伝えます。栄養は入力時の必須分類ではありません。後から二つを対等につなげられ、同じメモをいくつもの考えに使えます。つながりの件数で自動昇格はしません。詳しくは [中核設計](core-growth-loop.md)を参照してください。

## どんな人に届くか
- アイデアが多く整理しきれない人
- メモを見返せなくなる人
- 創作・研究・企画・発信を行う人
- 日記や内省を続けたい人
- 思考や感性を育てたい人

## どう助けるか
1. **書くハードルを下げる**: 完成前提を外し、一言入力を歓迎する
2. **忘れにくくする**: 再浮上で過去の種と再会できる
3. **育てやすくする**: 問い・タスク・記事案・プロジェクト案へ接続する
4. **流れを見える化する**: 継続テーマや関心変化を捉える
5. **創作・仕事に接続する**: 断片を具体的アウトプットに変換する

## その後どんな世界になるか
- 直感を捨てずに済む
- 未完成の考えが失われず育つ
- メモが情報ではなく未来の芽として機能する
- AI は決定者ではなく創造性を照らす補助になる
- ユーザーが自分の内側の森を継続的に歩ける

## 実装可能な機能への接続
- GrowthState（seed / sprout / tree / archived）で成長段階を管理
- resurfacingScore で再浮上候補を提示
- 現行の relatedSeedIds は既存関連を保持。公開前は無向Connectionを正本として移行し、必要な既存表示用のID配列を導出する（[保存契約](core-growth-data.md)）
- 元の本文と別の synthesis に本人の可能性と材料を保存し、芽の由来をたどれるようにする（新規設計・未実装）
- Transform Actions は既存の出力補助として保持。材料から芽を生む操作とは分ける
